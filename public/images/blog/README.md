# Blog cover images

Same convention as `public/images/diseases/README.md`: drop a file here named
after the post's slug (`content/blog/<slug>.mdx`), any of `.webp`/`.jpg`/
`.jpeg`/`.png`, and it replaces the placeholder automatically.
